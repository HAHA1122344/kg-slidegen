## 讲次
U11 循环队列（7 页）

## 教学目标
理解循环队列如何用取模实现空间复用，能正确区分队空与队满条件，并独立写出循环队列的实现代码

## 必须覆盖的概念（缺一不可）
- C1101 循环队列（掌握，复杂度 入队 O(1)，出队 O(1)）：把顺序队列的存储空间首尾相连，用取模运算让 rear 和 front 在到达末端后回到起点，从而复用空闲单元
- C1102 取模运算（掌握）：指针前移时使用 (index + 1) % maxsize，使下标在 [0, maxsize-1] 内循环，是循环队列实现的关键
- C1103 队空条件（熟练）：循环队列中 front == rear 表示队列为空
- C1104 队满条件（熟练）：为区分队空与队满，通常牺牲一个存储单元，队列满的条件是 (rear + 1) % maxsize == front
- C1105 队列长度计算（掌握，复杂度 O(1)）：循环队列元素个数为 (rear - front + maxsize) % maxsize
- C1106 循环队列的实现（熟练）：用 Python 列表模拟定长数组，维护 front、rear、maxsize 三个状态，所有指针移动均需取模
- S1002 循环队列的取模计算（熟练）：能正确写出指针前移与长度计算的取模表达式，并解释为何需要加 maxsize

## 讲解顺序（必须遵守，这是先修关系决定的拓扑序）
C1101 循环队列 → C1102 取模运算 → C1103 队空条件 → C1104 队满条件 → C1105 队列长度计算 → C1106 循环队列的实现 → S1002 循环队列的取模计算

## 必须纠正的典型误区
- MC03 错误说法：循环队列判满的条件是 rear == front
  正确理解：rear == front 是队空条件。判满需牺牲一个单元，条件为 (rear + 1) % maxsize == front。两者混淆会导致队空与队满无法区分
